# InnovateSec

Website for Innovate Securities Pvt. Ltd., built with React, Vite, Ant Design, React Router, and Swiper.

## Prerequisites

- Node.js (LTS recommended)
- Yarn or npm

## Installation

```bash
yarn install
```

or

```bash
npm install
```

## Development

Start the local dev server with hot module reloading:

```bash
yarn dev
```

or

```bash
npm run dev
```

The app will be available at the URL printed in the terminal (typically `http://localhost:5173`).

## Build

Create a production build:

```bash
yarn build
```

or

```bash
npm run build
```

Output is generated in the `dist` folder.

## Preview production build

```bash
yarn preview
```

or

```bash
npm run preview
```

## Lint

```bash
yarn lint
```

or

```bash
npm run lint
```

## Deployment (cPanel)

1. Create a production build:

   ```bash
   yarn build
   ```

2. Upload the contents of the generated `dist` folder to the `www` folder on cPanel.
